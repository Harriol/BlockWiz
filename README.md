# BlockWiz（方块巫师）

> 🧙 你的 Minecraft AI 全能助手

BlockWiz 是一个 Minecraft Fabric AI 助手模组。它通过自然语言交互，让玩家用对话的方式操控游戏世界 —— 无需记指令、不用学操作，想做什么直接说出来。

## 💡 设计理念

BlockWiz 采用 **插件式能力扩展** 架构：模组本体负责游戏内通信与指令执行，AI 后端负责理解玩家意图并调度对应能力模块。每个能力（建造、问答、操控等）作为独立模块叠加，互不耦合。

## ✨ 核心特性

- **🗣️ 自然语言驱动** — 在聊天框用口语描述需求，AI 自动理解并执行
- **🧩 能力可扩展** — 插件式模块架构，新功能即插即用
- **🧠 AI Agent 循环** — "思考 → 行动 → 观察 → 迭代"，自主完成复杂任务
- **📡 本地运行** — WebSocket 本地通信，无需服务器，不依赖外网
- **🛡️ 安全可控** — 仅监听 127.0.0.1，不暴露公网，无高危默认操作

## 🏛️ 技术架构

```
玩家聊天输入
     ↓
Fabric 模组（游戏通信层 / WebSocket 服务端）
     ↓  JSON 双向通信 (ws://127.0.0.1:25500)
Python AI 主控端（Claude Agent 循环）
     ↓
能力调度 → 模块 A / 模块 B / 模块 C / ...
```

| 层级 | 技术栈 | 职责 |
|------|--------|------|
| 游戏通信层 | Fabric Mod (Java) + WebSocket | 数据采集、指令执行、环境感知 |
| AI 主控层 | Python + Claude API | 意图识别、任务规划、能力调度 |
| 能力模块层 | 可插拔模块 | 各领域具体逻辑（建造、问答、操控等） |

## 📋 能力模块规划

### V1.0 — AI 智能建造 🏗️（开发中）

> 一句话建房：地基找平 → 墙体搭建 → 楼板铺设 → 屋顶生成 → 门窗开挖

- 自然语言描述建筑需求（尺寸、材质、样式、层数）
- AI 自动拆解任务，分步执行
- 自动感知地形、朝向，避免悬空和埋地
- 指令失败自动修正重试

## 🚀 快速开始

### 环境要求

- Minecraft 1.21.11（Fabric）
- Java 21+
- Python 3.10+
- Fabric Loader 0.19.3+
- Fabric API

### 编译模组

```bash
./gradlew build
```

产物位于 `build/libs/blockwiz-1.0.0.jar`，放入 Minecraft `mods` 文件夹即可。

> Python AI 后端将在功能开发阶段同步放出。
